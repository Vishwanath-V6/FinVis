# FinVis 3-5 Minute Demo Script

1. Start the app with `streamlit run app.py`.
2. Upload a financial annual report and select the analysis request.
3. Explain the SHA-256 cache and targeted page scan while processing.
4. Open Overview and identify only supported metrics.
5. Open Financial Analysis; filter one metric and one reporting scope.
6. Explain that period changes and ratios are calculated in Python, not by an
   LLM.
7. Open Evidence Explorer and select a metric. Trace the displayed value to its
   page, table, chunk, and raw extracted cell.
8. Ask for a supported metric and period. Show the answer and source citation.
9. Ask for a missing or unsupported number and demonstrate explicit abstention.
10. End with local deployment, tests, benchmark scripts, and known limitations.
